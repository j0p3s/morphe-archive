## 📱 Compatibility

- **Current release:** v2.0.0
- **App:** Anixart
- **Package:** com.swiftsoft.anixartd
- **Version:** 10.5
- **APK type:** APK
- **Patch:** Remove ads

For Anixart 10.0, use the previous [v1.0.0 release](https://github.com/Error404rt/Anixart-patches/releases/tag/v1.0.0).

## 🚀 Installation

1. Install the original **Anixart 10.5**.
2. Open Morphe Manager.
3. Click [Open in Morphe](https://morphe.software/add-source?github=Error404rt/Anixart-patches) or add https://github.com/Error404rt/Anixart-patches manually.
4. Select **Remove ads** and your preferred options.
5. Build and install the patched application.

## 🛠️ Development

This project uses the Morphe Patches Template and is built through GitHub Actions.

To build the MPP locally:

```bash
./gradlew buildAndroid
```

The output file is generated under patches/build/libs/patches-*.mpp.
