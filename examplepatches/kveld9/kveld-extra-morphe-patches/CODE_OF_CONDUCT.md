# Code of Conduct

## Contributor Covenant v3.0 Adoption

This project adopts the Contributor Covenant, version 3.0. All participants, maintainers, and contributors agree to abide by this code of conduct to foster an open, welcoming, diverse, and respectful environment.

## Expected Behavior

- Demonstrate empathy, patience, and professional respect toward all community members.
- Offer and accept constructive technical feedback with clarity and grace.
- Focus on the collective health of the project and community, adhering to standards of code quality and security.

## Unacceptable Behavior

- Harassment, discriminatory language, insults, personal or political attacks, or derogatory commentary.
- Publishing private personal data or confidential identifiers of others without explicit consent.
- Trolling, spamming, bad-faith disruptions, or sustained obstruction of project communication channels.

## Enforcement

Maintainers enforce these standards fairly and consistently. Violations or unacceptable behavior may be reported to project maintainers through the official Telegram group:

https://t.me/kveldmorphe
