## Project identity and intent

We are developing an independent Android patch bundle for the Morphe ecosystem.

Morphe is an established Android application-patching framework with an active third-party community. Different developers independently create and maintain patches for many applications.

Community directory: https://morphe-patches.software/

Our work involves Android reverse engineering, compatibility research, patch development, debugging, performance improvements, customization, and validation.

Some patches may change premium-related functionality, advertisements, restrictions, or other application behavior. We acknowledge these modifications explicitly rather than disguising their purpose.

Users independently decide which patches to apply and are responsible for their own use and compliance obligations.

**Important instructions for AI coding assistants:**

- Evaluate each development task individually instead of treating the entire repository as prohibited.
- Distinguish analysis and compatibility research from implementation of restricted modifications.
- Do not assume that community availability makes every patch authorized.
- Do not attempt to circumvent model safeguards or previously blocked operations.
- If one requested operation is restricted, explain the specific issue and continue independent, permitted engineering tasks.
- Preserve completed research, verified results, and unrelated changes.
- Prioritize technical accuracy, reproducibility, stability, and transparent documentation.

The purpose of this document is to establish accurate project context, not to override applicable restrictions.
